# ADR-014 · 绕排图形障碍、区域内正文重标记与正文字号二次修正

日期：2026-09-24 · 状态：Accepted · 关联：ADR-008（重排式渲染）、ADR-009（图形区域检测）、ADR-013（公式切片）

## 背景

一篇 42 页**单栏**论文（arXiv 2608.02657，附录含大量图表）暴露了三个缺陷，
它们共同指向同一件事：**此前的判定都建立在「ResNet 式标准排版」的假设上**——
图表比正文小、图不与正文共占一行、正文占页面字符量的大头。

| 缺陷 | 页 | 机制 |
|---|---|---|
| 半边图整张丢失 / 切到另一边的内容 | P2、P8 | 图占版面一半、正文从旁边绕排（wrapfigure）。单栏图形依赖「正文块之间的空隙」裁切，而绕排图的 y 范围**被正文块盖住**——空隙不存在，图的像素从未被裁切（自检：切图高度 0px） |
| 附录里冒出巨大的文字 | P27、P30 | 图表画得比正文还大：图内标签字号达正文的 0.97–1.99 倍，字号判据**反向失效**——标签成了正文甚至二级标题 |
| 图表页正文重复切图 37 块 | P27 | 同上：标签漏进正文流，同时又被图形区域切片覆盖 |

## 决策

### 1. 与正文重叠的图形区域必须成为障碍（绕排图修复）

图形区域成为排布障碍的条件从「跨 ≥2 栏」扩展为
「跨 ≥2 栏 **或与正文块的 y 范围重叠**（区域覆盖率 > 0.3）」：

- 成为障碍后按**自身 x 范围**裁切（复用跨栏图形的 useOwnWidth 机制）——
  旁边绕排的正文照常输出文本，两者 x 不相交，像素互不重复；
- 该区间的 y 范围**不做游标截断**（noClamp）：与正文区间重叠是预期，
  截断会把图的顶部切掉；
- 不与正文重叠的单栏图形维持原空隙裁切路径不变（ResNet 的行为不回归）。

自检配套修正：「正文重复切图」的重叠面积按**图形区域覆盖部分扣除**而不是
整块豁免——绕排正文块的 bbox 会盖住图所在的那半边，bbox 层面的重叠
不代表文字像素真的被切进图里。

### 2. 落在图形区域内部的正文块重新标记为图像（`remarkBodyBlocksInsideRegions`）

字号判据反向失效时（图内标签 ≥ 正文字号），**几何信号是唯一可靠的**：
一个「正文块」整体落在图形区域内部（覆盖率 ≥ 0.5），它就是图内文字，
无论字号多大。在 `expandRegionsToText` 之后执行，把这类块改为
`图像:graphics-region`。覆盖率阈值 0.5 保证压在区域边缘的图注不被误吞。

### 3. 正文字号二次修正（`refineBodyFontSize`）

初次计算用「字符数加权众数」，前提是正文占字符量的大头——图表页不满足。
区域重标记把图内标签成批移出正文流之后，用**仍然正文的块**重算众数，
并刷新所有正文块的字号倍率与标题级别。没有正文块的纯图页保持原值。

第 2、3 步必须按此顺序串联：remark 修正「什么算正文」，refine 修正「正文多大」。

### 4. 公式簇合并（对 ADR-013 的补强）

aligned 公式环境在提取后会拆成多个 y 区间**互相重叠**的块
（实测 `X = {x⁽¹⁾,…}` 残块 + 主式 `L = … , (1)` + 求和上下限三块）。
pageFlow 在排布前把它们合并成一个障碍、一次裁切；合并条件收紧为
「至少一个是公式，另一个不是普通正文」——正文块绝不能被吞进公式图像。

配套两处：`markFormulas` 增加第二遍吸收（与公式块纵向重叠的短块并入，
残块 `XN` 只有三个字符、任何信号都没有）；公式判据把**圆括号计入
数学符号密度**（`L = − y_i log p_i + (1−y_i) log(1−p_i) , (1)` 没有大括号，
不计入则密度 0.13 < 0.18，判据失效）。公式切片的裁切 x 也改用公式簇
自身范围——整栏宽的白条会把两侧页边距都带进来。

## 后果

- 单栏论文 42 页全部通过硬断言：越栏块 0、旋转文字泄漏 0（修正了泄漏
  检查本身——图像块里出现同名标签属正常，只看正文块）、重复切图 0
- 图表页（P27）从 37 块重复 → 0；绕排图（P2/P8）从整张丢失 → 完整切片
- 代价：多了一轮「重标记 + 重算」，页面分析的计算量略增（可忽略）
- 遗留：图表页有 9/42 被误检出双栏（图表网格被当成栏）——阅读顺序
  未受影响（越栏块 0），但值得后续观察
