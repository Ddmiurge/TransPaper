# I11 小结 · 单栏论文：绕排图、附录大字、公式补漏

> 迭代日期：2026-09-24 · 决策：[ADR-014](../../docs/adr/ADR-014-wrapped-figures-and-region-remark.md)
> 样本：arXiv 2608.02657v1（42 页单栏，附录图表密集）→ `fixtures/single-column-sample.pdf`

## 用户反馈（三个）

1. 公式一仍然被拿去翻译
2. 单栏论文里有些图只占半边，切片把另一边的内容截了进去
3. 附录中有些字字体过大

## 根因（共同点：ResNet 式标准排版的假设全部失效）

| 缺陷 | 机制 |
|---|---|
| 公式漏判 | aligned 环境拆成 3 个互相重叠的块；主式 `L = − y_i log p_i + …` 没有大括号，圆括号不计入密度 → 0.13 < 0.18 |
| 绕排图丢失 | 图占右半边、正文绕排；图形区域 y 范围被正文块盖住 → 空隙裁切永远不发生 → **整张图消失**（切图高度 0px） |
| 附录大字 | 图表画得比正文大：标签 0.97–1.99 倍正文字号，字号判据反向失效；图表页正文占比小，字号基准也被污染 |

## 修法（ADR-014）

1. **绕排图障碍**：图形区域与正文块重叠（覆盖率 > 0.3）→ 成为障碍，
   按自身 x 裁切；该区间不做游标截断（noClamp）
2. **区域内正文重标记**：块整体落在图形区域内（≥0.5）→ 图像:graphics-region，
   无论字号多大
3. **正文字号二次修正**：重标记后用剩余正文块重算众数，刷新字号倍率与标题级别
4. **公式补强**：圆括号计入密度；第二遍吸收（与公式块纵向重叠的 ≤3 行 ≤40 字块）；
   pageFlow 公式簇合并成一个裁切；公式切片用自身 x 范围

## 效果（截图 sc-formula2 / sc-page27 / sc-wrapfig）

- 公式 (1) `ℒ = −1/N Σ[yᵢ log pᵢ + (1−yᵢ) log(1−pᵢ)]`：完整切片、
  编号右对齐、无译文；行内 `pᵢ`、`yᵢ` 下标正确
- P27：6×6 图表网格整体切片，**零大字标签、零重复**（37 块 → 0）
- P2/P8：绕排图完整呈现，按自身宽度，旁边正文照常
- 42 页硬断言全过：越栏 0、泄漏 0、重复切图 0、未覆盖路径 0

## 过程中的坑

- **泄漏检查自身误报**（P30）：旋转标签在图里有旋转/水平两份副本，
  水平副本合法地进了图像块，文本匹配却把它算泄漏 → 检查只看正文块
- **编辑丢失**：一次多段编辑脚本漏了 `write_text`，公式簇合并与
  useOwnWidth 两处改动没落盘，导致排查绕排图时多花一轮——
  多段编辑后必须 grep 验证每处都真的写进去了
- **域层不能碰 `process.env`**：浏览器里没有 `process`，整个页面白屏
  （`ReferenceError: process is not defined`）。诊断打印只能放测试里
- item 阈值断言（>50）是按 ResNet 标定的，整页图表的附录页合法地只有 47 项 → 放宽到 10
