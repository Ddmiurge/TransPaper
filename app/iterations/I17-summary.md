# I17 小结 · 文字表格识别（统一切片保留原样）

> 迭代日期：2026-09-27 · 样本：acl-sample.pdf（主）、two-column / single-column（防误报基线）
> 决策记录见 [ADR-015](../docs/adr/ADR-015-text-tables-as-slices.md)
> 触发：用户确认的迭代计划（I17 表格 → I18 手动改判 → I19 行内公式）。

## 目标

ACL / NeurIPS 式排版的表格是「小字号文字 + 列间隙」，既无位图也无足够路径，
是 R3「表格保持原样」最后漏网的非文本元素——此前被逐行切成碎条，行列结构散架。

## 方案（ADR-015）

- `domain/tables.ts`：行级判据——一行内 ≥2 个大间隙（≥1.0 × 正文字号）+
  间隙位置跨行对齐（容差 16px）+ ≥3 行连续（行距 < 2.0 × 正文字号）。
  阈值全部在 ACL 真实表格上标定（探针实测 p6/p14/p15/p16）。
- 三道防误报闸：① 块级排除公式/文献/作者/页码/标题（**不要求 isBodyText**——
  ACL 表格行是小字号图内文字，要求正文会全军覆没）；② **长词密度**
  （组平均 ≤4 个 ≥3 字母词、占比 ≥60%——真实表格 0.75–3 个，
  「正文 + 行尾行内公式」误报形态 7–9 个）；③ 共享列边界。
- 接入走 I13 验证过的同一条路：表格矩形并入 `figureRegions`（域内合并、
  `remarkBodyBlocksInsideRegions` 兜底）**并**由调用方并入 `figurePaths`
  （表格无矢量路径，不并则空隙切图不发生——同位图框的坑）。
  接线点：`PageFlowBlock`、`App.tsx`、`realPdf.test.ts` 三处。
- 渲染结果：整表**一个完整切片**（不再逐行碎条），像素零损失，不翻译。
  有意不做 HTML 表格化（违反 R3「保持原样」，且需单元格级模型改动，留作增强）。
- 顺带修正：`App.tsx` 的 `figureRegions` 改用域层统一算好的那份
  （原来自筛「跨栏」，同一份几何算两遍迟早漂移——与 PageFlowBlock 对齐）。

## 效果

- **ACL 17 页检出 11 个表格区域**（p6×1、p14×5、p15×3、p16×2），与人工核对完全一致；
  p6 主结果表（11 行）在文档流中成为单一完整切片（覆盖率 >80% 断言）。
- ResNet / 单栏基线：**零正文块被改标**；图内标签产生的候选区域与图形区域合并，无害。
- 探针阶段的真实误报（单栏 p6「As shown in Table 2…」正文段落）被长词密度闸排除，
  已固化为回归断言。
